# 수상·수료 증빙 원장

채용 지원서의 정형 입력란에 사용할 정보를 한곳에서 관리한다. 수상 5건과 수료 1건의 증빙 PDF 사본은 2026-11-26 확인했다. 이 공개 저장소에는 원본 PDF, 상장 이미지, 증서번호 및 타인 개인정보를 올리지 않는다.

## 수상경력 — 지원서 입력용

| 상훈명 | 수여기관 | 수상일자 | 수상내역 |
|---|---|---|---|
| 제22회 임베디드 소프트웨어 경진대회 | 임베디드소프트웨어·시스템산업협회 | 2024.11.29 | webOS 부문 입선 |
| 제1회 전국 장애·비장애 대학생 창업경진대회 | 한경대학교 | 2022.02.10 | 대상 |
| 제6회 글로벌 이노베이터 페스타(GIF 2021) | 교육부 | 2021.11.13 | 메이커톤 KT 트랙 대상 |
| 2019 국제로봇콘테스트 WCRC | 산업통상자원부 | 2019.12.13 | micro:bit 창작 대학일반 부문 금상 |
| 2019 대한민국 마이스터대전 WCRC 2차본선 | 과학기술정보통신부 | 2019.11.14 | micro:bit 창작 대학일반 부문 1위(금상) |

**입력 원칙:** 상훈명은 대회명, 수여기관은 기관명, 수상일자는 상장 기재 날짜, 수상내역은 참가 부문과 상격으로 작성한다. 출품 내용과 개인 기여는 수상내역에 포함하지 않고 프로젝트 경험에서 관리한다. 지원서에 별도 기준이 있다면 그 기준을 우선한다.

## 수상 증빙 확인 기록

| 수상일자 | 상장상 수여자(직함) | 증빙 상태 | 관련 경험 |
|---|---|---|---|
| 2024.11.29 | 임베디드소프트웨어·시스템산업협회 회장 | 상장 사본 확인 | [webOS 스마트 화분](../experiences/webos-smart-planter.md) |
| 2022.02.10 | 한경대학교 총장 | 상장 사본 확인 | [허밍블럭스](../experiences/hummingblocks.md) |
| 2021.11.13 | 부총리 겸 교육부장관 | 상장 사본 확인 | [GIF KT 메이커톤](../experiences/gif-2021-kt-makerthon.md) · [근거 원장](../experiences/gif-2021-kt-makerthon-evidence-ledger.md) |
| 2019.12.13 | 산업통상자원부장관 | 상장 사본 확인 | [Paperware](../experiences/paperware.md) |
| 2019.11.14 | 과학기술정보통신부장관 | 상장 사본 확인 | [WCRC 스마트 타이머 무드등](../experiences/linkcube-2019.md) |

- 2021 GIF의 실제 훈격은 부총리 겸 교육부장관으로 확정한다. 모집 공고의 예정 훈격과 실제 상장은 구분한다.
- 2019 WCRC 두 건은 진행 중이던 Paperware 계열 micro:bit 활동의 출품 기록과 연결된다.
- 대회 수상과 개인 소프트웨어·하드웨어 구현 기여는 구분한다.
- 허밍블럭스 관련 다른 팀 수상 기록(KNU 창업경진대회 대상, 소셜벤처 경연대회 TS청년벤처상·대구광역시장상)은 개인 수상 여부와 정확한 날짜가 미확인되어 위 개인 수상 목록에 포함하지 않는다.

## 관리 원칙

- 수상·수료 사실 및 지원서 입력 기준의 기준 문서는 이 파일로 한다.
- 확인되지 않은 날짜, 훈격, 시간은 추정하여 확정하지 않는다.
- 증빙 원본은 개인 보관 자료에서 관리한다.
- [마스터 이력서](../resume.md)와 [경험 원장](../experiences/README.md)은 필요한 요약만 남기고 이 문서를 참조한다.
