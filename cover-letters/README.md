## 보관 원칙

- 과거 문장을 현재 기준으로 몰래 고치지 않습니다.
- 원문을 복구한 경우에는 당시 제출/작성 버전을 그대로 보관합니다.
- 개선본을 만들 경우 원본과 분리하거나 변경 이유를 기록합니다.
- 공고 문항, 글자 수 제한, 지원 직무를 함께 남깁니다.
- 기억만으로 과거 자기소개서 본문을 재작성해 `원문`이라고 표시하지 않습니다.
