# 자기소개서 아카이브

개인 Notion의 `자소서` 페이지와 별도 지원서 페이지에서 실제 작성된 자기소개서를 회사별 Markdown 파일로 옮겨 보관합니다.

## 아카이브 기준

- 과거 문장을 현재 기준으로 다시 고치지 않습니다.
- 한 문항에 초안과 수정안이 여러 개 있으면 **가장 마지막으로 실제 작성된 비어 있지 않은 후보**를 보관합니다.
- `---` 뒤에 새로운 전체 답변이 있으면 뒤의 답변을 최신 후보로 사용합니다.
- 댓글에 수정 제안만 있고 실제 수정본이 작성되지 않은 경우에는 기존 본문을 그대로 보관합니다.
- 당시 비워 둔 값이나 표현은 임의로 보완하지 않습니다.
- 기업 조사와 채용 정보는 제외하고 실제 자기소개서 답변을 중심으로 보관합니다.
- 원본에 없는 문항이나 답변을 새로 만들지 않습니다.
- 회사명이 확인되지 않는 지원서는 임의로 추정하지 않습니다.

## 원문은 확인했지만 파일을 만들지 않은 항목

### 한미그룹

한미그룹 페이지에는 제조 IT 시스템지원 직무 조사, MES/ERP/WMS 관련 자료와 자기소개서 문항은 확인되지만, 현재 확인 가능한 범위에서 실제 작성된 답변 후보는 찾지 못했습니다. 따라서 문항만 있는 빈 자기소개서 파일이나 추정 답변은 만들지 않았습니다.

## 원문에서 확인되는 특이사항

### 케이뱅크

현재 Notion 원본에서 실제 답변이 확인되는 문항은 1번, 2번, 4번입니다. 3번 답변은 확인되지 않아 파일에도 새로 만들지 않았습니다.

### DN솔루션즈

한 페이지에 제어설계와 R&D기획 방향의 여러 초안이 함께 남아 있습니다. 페이지 후반과 당시 피드백 흐름을 기준으로 R&D기획 방향의 최신 후보를 보관했습니다.

### SK하이닉스

일반 자기소개서뿐 아니라 AI 활용 경험기술서와 직무 경험기술서가 함께 있어 하나의 파일에 모두 보관했습니다. HummingBlocks의 추론 시간 및 정확도 비교, CPU와 CNN Accelerator의 검증 과정처럼 다른 지원서보다 상세한 기술 기록도 포함되어 있습니다.

### 2026-08 미분류 지원서

Notion 원본에 회사명이 기재되어 있지 않아 `unclassified-solution-sw`로 보관했습니다. 직무 전문성 문항과 Mallo, HummingBlocks를 활용한 AI 기반 문제 해결 경험은 원문에 있는 그대로 유지했습니다.
