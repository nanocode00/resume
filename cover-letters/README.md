# 자기소개서 아카이브

이 폴더에는 회사별로 실제 작성했던 자기소개서를 보관합니다.

현재 인덱스는 개인 Notion의 `자소서` 페이지를 기준으로 확인한 기록입니다. 과거 원문을 GitHub로 옮길 때는 문장을 임의로 고치지 않고, 당시 작성본과 수정 후보를 구분해서 보관합니다.

## 파일명 규칙

```text
YYYY-MM-company-role.md
```

예:

```text
2026-06-vatech-sw-imaging.md
2026-06-canon-korea-solution-engineer.md
```

## 특히 재사용 가치가 높은 원문

### SK하이닉스 경험기술서

경험의 기술적 수치와 역할이 다른 자소서보다 상세하게 기록되어 있습니다.

- HummingBlocks: Chaquopy 기반 평균 처리 시간 9.1초
- TFLite 적용 후 평균 5.4초로 단축
- 인식 정확도 90% → 57%로 하락해 기존 방식을 유지한 판단 근거
- Crypto LOB Prediction의 데이터/모델 실험 과정

이 내용은 `experiences/`의 사실관계를 보강할 때 우선 참고합니다.

### 2026-08 미분류 지원서

최근 HW/SW 경험이 구체적으로 정리되어 있습니다.

- Verilog CPU의 예외 처리와 신호 타이밍 문제
- CNN Accelerator의 PyTorch 양자화, RTL 검증, OpenROAD 합성
- RTL MNIST 1,000장 기준 96% 기록
- Netlist 시뮬레이션에서 결과 검증을 끝내지 못한 한계까지 명시
- webOS 스마트 화분의 I2C 명령 규칙 및 센서 데이터 구조
- Mallo의 AI 기반 문제 해결 경험

성공한 결과만 남기지 않고 검증하지 못한 부분도 기록되어 있어 면접 및 경험 정리 자료로 활용 가치가 높습니다.

## 보관 원칙

- 과거 문장을 현재 기준으로 몰래 고치지 않습니다.
- 원문을 복구한 경우에는 당시 작성/제출 버전을 그대로 보관합니다.
- 한 페이지에 여러 수정안이 있으면 `초안`, `수정안`, `최종 후보`처럼 구분합니다.
- 공고 문항, 글자 수/바이트 제한, 지원 직무를 함께 남깁니다.
- 기업 조사 내용과 실제 자기소개서 답변을 구분합니다.
- 기억만으로 과거 자기소개서 본문을 재작성해 `원문`이라고 표시하지 않습니다.
- Notion에서 내용이 불완전하거나 회사가 미분류된 문서는 그대로 표시하고 임의로 회사명을 추정하지 않습니다.
