## 1. 지원분야를 선택한 이유와 본인이 이 직무에 적합하다고 판단할 수 있는 근거를 본인의 강점 및 직무경력을 중심으로 기술해주십시오 (1000자)

Java/Go 개발 분야를 선택한 이유는 사용자의 요청과 데이터가 서비스 로직, 데이터베이스, 결과 처리로 이어지는 구조를 설계하고 구현하는 일에 흥미를 느껴왔기 때문입니다. 티맥스소프트의 플랫폼 제품은 기업 업무의 기반에서 동작하는 소프트웨어인 만큼, 기능 구현뿐 아니라 입력 데이터가 어떤 구조로 처리되고 안정적으로 결과를 만들어 내는지 이해하는 태도가 중요하다고 봅니다.

직무에 적합하다고 판단하는 강점은 주어진 데이터나 요구사항을 서비스에서 동작 가능한 데이터 구조와 처리 로직으로 구체화하는 점입니다. 이 강점은 허밍블럭스 개발 과정에서 드러났습니다. 허밍블럭스는 실물 블록을 촬영하면 인식 결과를 음악으로 실행하는 시각장애인 코딩교육용 앱입니다. 개발 과정에서 사진 촬영 데이터를 Python 기반 AI 처리 로직으로 전달하고, 반환된 인식 결과를 Java 앱에서 사용할 수 있는 형태로 가공하는 후처리 알고리즘을 작성했습니다. 인식 결과를 그대로 표시하는 데 그치지 않고, 어떤 블록이 어떤 순서로 실행되어야 하는지, 음악 재생에 필요한 정보는 어떤 구조로 관리해야 하는지 고민하며 플레이 로직에 맞는 데이터 구조를 설계했습니다.

빔웍스 현장실습에서는 이러한 강점을 백엔드 개발 관점으로 확장했습니다. DealFlow 프로젝트에서 Figma에 올라온 디자인을 기반으로 요구사항 문서를 정리했고, 화면에서 필요한 데이터와 동작을 확인하며 데이터베이스 설계, SQL 작성, DTO 작성 등을 수행했습니다. 그 과정에서 변경되는 화면과 요구를 문서와 구조에 계속 반영하며, 개발 전 단계의 정리도 구현 품질에 영향을 준다는 점을 체감했습니다. 이를 통해 개발자는 화면이나 요구를 그대로 옮기는 사람이 아니라, 요구사항을 데이터 구조와 객체 흐름으로 바꾸어 실제 동작 가능한 형태로 만드는 사람이어야 한다는 점을 배웠습니다.

## 2. 자발적으로 도전하였던 경험과 그 과정에서 무엇을 배웠는지를 서술해주십시오 (1000자)

자발적으로 도전했던 경험은 두 가지입니다. 첫 번째는 알고리즘 실습 수업에서 Go를 직접 학습해 본 일입니다. 수업에서는 주로 C++ 예시 코드가 제공되었지만, 채점 가능 언어 목록에서 처음 보는 Go를 발견하고 호기심이 생겼습니다. 웹에서 자료를 찾아 변수 선언, 조건문, 반복문, 입출력 방식 등 기본 문법을 익혔고, 수업 예시로 나온 C++ 코드를 Go로 옮겨 보며 같은 동작이 나오는지 확인했습니다. 짧은 시도였지만 새로운 언어를 배울 때는 문법을 읽는 것보다 작은 코드를 직접 바꿔 보고 실행해 보는 과정이 이해에 더 효과적이라는 점을 배웠습니다.

두 번째는 webOS 기반 스마트 화분 프로젝트를 수업 이후에도 이어 간 경험입니다. 이 프로젝트는 원래 종합설계프로젝트 과목에서 LG와 산학협력으로 진행한 과제였지만, 수업이 끝난 뒤에도 팀원들과 함께 webOS 기반 제품 제작 대회에 도전했습니다. 당시 webOS OSE를 라즈베리파이에 올려 구동했고, 토양습도센서, 온습도센서, 네오픽셀 링, 물 공급용 모터를 연결해야 했습니다.

처음에는 webOS의 GPIO API로 직접 제어하려 했지만, 여러 센서와 액추에이터를 안정적으로 다루기에는 적합하지 않다고 판단했습니다. 그래서 아두이노가 센서값을 읽고 장치를 제어한 뒤 라즈베리파이와 통신하는 구조로 바꾸었습니다. 초기에는 SPI 통신을 적용하려 했지만 원하는 방식으로 동작하지 않아 I2C로 전환했고, 아두이노에는 요청에 따라 센서값을 전달하거나 네오픽셀 색상과 모터를 제어하는 코드를 올렸습니다. 라즈베리파이에서는 JsService를 통해 명령을 보내고, UI에서는 실시간 센서값 표시와 버튼을 통한 네오픽셀 제어를 구현했습니다. 이 과정은 webOS 부문 입선이라는 결과로도 이어졌고, 수업 결과물을 대회 수준의 제품으로 다듬는 경험이 되었습니다.

두 경험을 통해 도전은 새로운 기술을 써 보는 데서 끝나지 않고, 맞지 않는 방식을 발견했을 때 구조를 바꾸며 동작 가능한 형태를 찾아가는 과정이라는 점을 배웠습니다.

## 3. 업무 및 협업 과정에서 나타나는 본인의 성향(강점과 보완점)을 구체적인 사례와 함께 작성해 주세요. 또한, 보완점을 개선하기 위해 어떤 노력을 하고 있는지도 함께 기술해 주세요. (1000자)

업무와 협업 과정에서 나타나는 강점은 진행에 필요한 빈틈을 먼저 찾고 움직이는 점입니다. 역할이 나뉘어 있어도 디자인, 리소스, 기능, 테스트가 맞물리므로, 맡은 부분만 기다리기보다 막힌 요소를 확인하고 해결하려고 합니다.

허밍블럭스에서 디자이너 UI를 바탕으로 안드로이드 프로토타입을 구현하던 중, 로티 파일로 만든 캐릭터 애니메이션의 첫 프레임 이미지가 필요했습니다. 디자이너가 로티 리소스를 변환한 GIF를 전달해주면 이를 분해해 첫 이미지를 PNG로 추출해야 했지만, 파일 전달이 지연되었습니다. 그래서 제작 방식을 확인했고, 사용 중이던 로티 플랫폼에서 GIF를 직접 추출할 수 있다는 점을 알게 되어 필요한 이미지를 만들었습니다. 캐릭터의 80% 검은색 이미지 제작이나 위치와 크기 조정이 필요할 때도 있었는데, 이때도 디자이너 지원을 기다리기보다 포토샵 사용법을 배워 직접 만들었습니다. 이 경험을 통해 협업은 결과물을 기다리는 일이 아니라, 서로의 작업이 이어지도록 필요한 부분을 메우는 과정이라고 느꼈습니다.

보완점은 더 나은 방법을 찾는 과정에서 일정이 지연될 때가 있다는 점입니다. 허밍블럭스 플레이스토어 업데이트를 준비할 때, 이미지 인식용 PyTorch 모델을 Chaquopy 환경에서 실행하다 보니 속도가 느린 문제가 있었습니다. 촬영 후 결과가 나오기까지 시간이 길어지면 사용성이 떨어질 수 있다고 판단했고, 파이썬으로 모델을 실행하는 방식 자체가 속도 저하의 원인일 수 있다고 보았습니다. 그래서 모델을 TFLite로 변환한 뒤 Java에서 실행하는 방식을 시도했습니다. 하지만 두 방식의 속도, 인식 정확도, 앱 내 처리 흐름을 비교하는 데 시간이 많이 필요했고, 플레이스토어 업로드 일정이 늦어진 경험이 있습니다.

이후에는 개선 작업 전 이번 버전에 반영할 항목과 다음 버전으로 넘길 항목을 먼저 나누고 있습니다. 변경 방식이 기존 기능에 미치는 영향, 비교 기준, 테스트 범위를 미리 정해 일정 안에서 검증 가능한 개선을 진행하려고 노력하고 있습니다.

## 4. 당사에 지원한 사유와 입사 후 어떤 포부와 비전을 가지고 업무에 임할 것 인지 지원분야의 업무수행계획을 기반으로 기술해 주십시오. (1000자)

티맥스소프트에 지원한 이유는 기업의 핵심 업무를 안정적으로 지탱하는 플랫폼 소프트웨어 개발에 매력을 느꼈기 때문입니다. 티맥스소프트는 미들웨어와 기업용 플랫폼을 중심으로 고객의 업무 시스템이 안정적으로 운영되도록 돕는 회사라고 이해했습니다. 사용자가 직접 보는 화면 뒤에는 요청 처리, 데이터 구조, 예외 상황, 성능과 같은 요소가 맞물려야 서비스가 안정적으로 동작한다고 생각합니다. Java/Go 개발자로서 이러한 흐름을 이해하고, 고객 업무 환경에서 신뢰할 수 있는 기능을 구현하는 개발자가 되고 싶습니다.

입사 후 3개월 동안은 제품 구조와 개발 프로세스를 빠르게 익히는 데 집중하겠습니다. 담당 제품의 아키텍처, 주요 모듈, 코드 작성 방식, 테스트 기준, 배포 흐름을 파악하고, 작은 수정이나 기능 구현부터 정확하게 수행하겠습니다. 특히 Java 기반 역량을 바탕으로 Go가 사용되는 영역도 함께 학습하며, 언어 차이보다 제품 안에서 데이터와 요청이 어떻게 흐르는지 이해하는 데 초점을 두겠습니다.

6개월 이후에는 맡은 기능을 안정적으로 구현하는 개발자가 되겠습니다. 요구사항을 바로 코드로 옮기기보다 필요한 데이터 구조, 처리 순서, 예외 상황을 먼저 정리하고 구현하겠습니다. 또한 테스트 가능한 단위로 기능을 나누고, 성능이나 안정성에 영향을 줄 수 있는 부분을 동료와 공유하며 품질을 높이겠습니다. 고객 업무에 사용되는 플랫폼인 만큼 작은 오류도 크게 이어질 수 있다는 책임감을 가지고 개발하겠습니다.

1년 이후에는 제품 구조를 더 넓게 이해하며 개선점을 제안할 수 있는 개발자로 성장하고 싶습니다. 반복되는 처리 흐름이나 테스트가 필요한 영역을 찾아 개선하고, 기능 구현뿐 아니라 유지보수성과 확장성까지 고려하겠습니다. 이후에는 고객 요구가 제품에 반영되는 과정을 이해하고, 팀의 개발 속도와 품질을 함께 높이는 구성원이 되겠습니다. 장기적으로는 티맥스소프트의 글로벌 AI 비즈니스 플랫폼이 더 안정적이고 신뢰받는 제품으로 성장하는 데 기여하겠습니다.
