# 네모감성 초기 메이커·micro:bit 프로젝트 — 자료 발굴 원장

> 상태: 2026-10-24 1차 조사 + 사용자 직접 기여 확인 반영. **소스 원본·당시 자료와 사용자 진술에 의해 구분된 사실**을 기록하며, 직접 코딩과 참고용 샘플을 분리한다. Paperware의 2018년 기록, 2019년 Link Cube, 군 복무 이후 Paperware용 PCB 활동을 하나의 연속 프로젝트로 가정하지 않는다.

## 조사 범위

사용자 보관 Google Drive의 `네모감성/` 폴더 및 다음 하위 폴더를 검토했다.

- `팀플/1. paperware프로젝트/`
- `팀플/마이크로비트 코드/`, `팀플/drone/`, `팀플/드론 코드/`

공유 여부가 확인되지 않은 원본 Drive URL/ID 및 개인 정보를 공개 저장소로 복제하지 않는다. 개별 출처는 폴더 경로·파일명으로 역추적한다.

## 기술적으로 확인한 소스

### 2018 micro:bit MicroPython — `controller.py` (**본인 직접 작성, 사용자 확인**)

- A/B 버튼 조합을 `U`(up), `D`(down), `S`(stop) 라디오 메시지로 전송.
- 버튼을 누르지 않을 때 가속도 센서 X/Y값을 읽고 절댓값 70 이하는 0으로 간주하여 미세 움직임을 제거.
- 두 축 값의 자릿수 길이를 붙인 문자열로 전송하고, 5×5 LED matrix에 상하좌우/대각 방향 표시.
- `radio_test.py`는 명령 수신 후 LED 방향 표시를 수행함. 이 파일은 발신 `controller.py`의 동작을 수신측에서 확인하려는 테스트 구현으로 해석 가능하지만, **이 파일의 개인 작성 여부와 실제 통신 성공은 확인되지 않음**.
- **검증 경계:** 직접 구현이 확인된 것은 컨트롤러 송신·입력 처리 부분이다. 드론 자체의 제어기 구현이나 비행 완료까지 증명하지 않음.

### 2018 Arduino — `drone.ino` (**드론 관련 도서 제공 예제, 개인 저작물 아님**)

**출처/기여 구분:** 사용자가 드론 관련 도서의 제공 자료라고 명확히 확인했다. 아래는 코드에 포함된 **참고 기술 구성**일 뿐, PID 제어기·IMU 필터·Arduino 비행제어 소프트웨어를 직접 구현한 이력으로 사용할 수 없다. 도서명·예제 라이선스는 별도 확인 필요.

- `MPU6050`(I2C 주소 `0x68`) 가속도/자이로 14바이트 읽기, 초기 센서 보정 및 기울기 추정.
- 자이로 적분값과 가속도 추정값을 `ALPHA=0.96`으로 결합하는 complementary filter 구현.
- roll/pitch/yaw 목표값·변화율을 입력으로 하는 `dualPID` 함수와 모터 4개 PWM 범위 0~255 제한 구현.
- `Serial1`로 들어온 MSP 형식 명령을 파싱해 throttle 및 기울기 목표값을 조정하는 경로가 있음.
- 실제 비행·안정화 성능·제어 루프 안전성은 확인되지 않음. 소스에 일부 점검 필요 표현이 존재하므로 완성형 비행제어기 또는 성공적 비행이라 단정하지 않음.

### 2019 무드박스 및 2020 교육 코드

- `추가 자료설명.pptx`는 NeoPixel RGB/밝기 범위, 버튼 A/B에 따른 분기, 기울기 X/Y/Z축 기반 색상 변화와 소등 조건을 설명.
- `microbit/moodlight-final/`, `moodlight-5sec/`에는 여러 main/controller HEX 변형이 남음.
- 2020 `교육자료/examples/`에는 LED 출력, 버튼·조건문, 조도, 자기장, 가속도, servo, NeoPixel 및 기초·심화반 자료가 정리되어 있음. 일부 `microbit-1조/2조/3조.hex`는 학생 또는 팀별 산출물일 가능성이 있어 개인 제작으로 귀속하지 않음.
- HEX는 배포·시연 후보 artifact라는 근거이지 실제 현장 동작이나 개인 저작의 결정적 증거는 아님.

## 이력서 선별 시 권장 구조

1. **Paperware PCB 개선:** 개인 회고에서 비교적 명확한 설계/발주/시제품 사례. 기존 `paperware.md`의 핵심 유지.
2. **micro:bit 무선 컨트롤러:** `controller.py` 직접 구현이 확인됐으므로 **버튼/가속도 입력 처리 → 라디오 명령 패킷 전송 → LED 상태 표시**를 개인 SW 사례로 분리할 수 있음. **책의 `drone.ino` 내부 알고리즘은 기여 실적에서 제외.**
3. **Link Cube/무드박스/교육:** SW+HW+교육을 결합한 장기 메이커 활동의 보조 사례. 개인 작성 코드·운영 실적의 근거를 더 확인하기 전에는 광범위한 성공/성과 주장 금지.

## 검증 질문 (자료 확인 이후에만 사용자 기억을 요청)

- **작성자 확인 완료:** `controller.py`는 사용자 직접 구현, `drone.ino`는 드론 관련 도서의 제공 예제. 추가 질문은 저작자 재확인이 아니라 **컨트롤러 실물 테스트와 드론 연동 결과**에 관한 것.
- 2019 무드등/Link Cube의 main/controller 코드에서 직접 담당한 범위는 무엇이었는가?
- 2018 Paperware와 군 복무 이후 NeoPixel PCB 설계는 동일 사업의 재개인가 별도 프로젝트인가?
- 2020 기초·심화 예제와 교육용 무드등에서 직접 제작한 자료와 실제 교육 회차는 어느 부분인가?
- 2019 WCRC 수상작의 실제 작동 범위 및 개인 기술 역할은 무엇인가?

본 원장 내용 중 발표자료의 **기획/제안**, 코드·HEX의 **산출물 존재**, 사용자 확인된 **본인 직접 구현**, **외부 도서 예제**, 실제 **시험/성과**를 계속 분리한다.
