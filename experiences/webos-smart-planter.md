# webOS Smart Planter

## 한 줄 요약

Raspberry Pi의 webOS OSE, Arduino, React UI, AWS를 연결해 센서 수집부터 장치 제어와 사용자 화면까지 하나의 흐름으로 구성한 LG 산학 연계 종합설계 프로젝트.

## 주요 구성

- Raspberry Pi
- webOS OSE
- Arduino
- 센서 및 액추에이터
- React UI
- AWS

## 맡은 역할

- Arduino 기반 센서 및 액추에이터 연결과 하드웨어 제어
- Raspberry Pi와 장치 사이의 데이터 연결
- React UI 일부 구현
- 센서 이름, 단위, 전송 주기, 제어 기준 등 팀 간 데이터 규격 조정

## 핵심 경험

각 파트가 개별적으로 동작하는 것만으로는 전체 시스템이 완성되지 않았습니다. 센서에서 생성한 값이 Raspberry Pi와 서비스 계층을 지나 UI에 표시되고, 다시 사용자 입력이 장치 제어로 이어지려면 각 파트가 같은 데이터 규격을 사용해야 했습니다.

센서 이름과 단위, 데이터 전송 주기, 제어 기준처럼 서로 맞지 않으면 바로 연결 문제가 생기는 항목을 팀원들과 조정하며 시스템 전체 흐름을 맞췄습니다.

## 결과

- 2024 임베디드 소프트웨어 경진대회 webOS 부문 입선
