# Verilog Single-cycle CPU

## 한 줄 요약

MIPS 형태의 단일 사이클 CPU를 Verilog로 구현하고 CP0를 추가해 syscall 예외 처리와 ERET 복귀 흐름까지 구현한 프로젝트.

## 구성

- Control
- ALU
- Register File
- Data Memory
- Instruction Memory
- Immediate Extender
- CP0

## 예외 처리 흐름

1. `syscall` 발생
2. 현재 실행 흐름에서 복귀에 필요한 PC를 EPC에 저장
3. 예외 처리 루틴 주소로 PC 변경
4. 예외 처리 수행
5. `ERET` 실행
6. EPC를 사용해 원래 흐름으로 복귀

## 주요 디버깅 항목

- ALU 입력 순서
- ALU Decoder 제어값
- RegDst 제어
- ZeroExtend 제어
- EPC 저장 시점
- 예외 발생 신호
- PC 변경 흐름

## 문제 해결 방식

CPU는 여러 모듈과 제어 신호가 동시에 연결되어 있기 때문에 최종 출력만으로 원인을 찾기 어려웠습니다. 파형과 명령어 실행 순서를 기준으로 각 사이클의 제어 신호, ALU 입력과 결과, 레지스터 값, PC 변화를 따라가며 문제가 시작되는 지점을 좁혔습니다.

특히 예외 처리에서는 `syscall` 발생 시점과 EPC에 저장해야 하는 주소, 예외 루틴으로 이동하는 PC 흐름, ERET 복귀가 서로 맞아야 했기 때문에 이 흐름을 중심으로 검증했습니다.
