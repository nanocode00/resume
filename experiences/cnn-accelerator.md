# CNN Accelerator — HW 이식 파이프라인

## 한 줄 요약

PyTorch에서 양자화한 CNN을 Verilog 가속기로 옮기고, RTL 검증과 OpenROAD 합성 이후까지 SW/HW 결과의 정합성과 정확도를 확인한 프로젝트.

## 전체 흐름

`PyTorch 양자화 → Verilog 구현 및 검증 → OpenROAD 합성 → 정확도/PPA 평가`

## 모델

- 5×5 커널 기반 2단 CNN
- MNIST 데이터 사용

## 주요 작업

- PyTorch에서 weight, bias, 레이어별 출력값을 정수화
- 정수화 결과를 HW에서 읽을 수 있도록 2진수와 16진수 텍스트로 저장
- 레이어별 출력값을 SW와 HW에서 비교
- 필요할 경우 MAC 단위 연산까지 내려가 차이가 시작되는 지점 추적
- RTL 합성 후 `tb_compare`에서 RTL과 Netlist를 동시에 실행해 결과 비교
- MNIST 1,000장 단위로 기능과 정확도 유지 여부 검증
- OpenROAD와 ASAP7 공정을 사용해 합성 및 PPA 평가

## 문제 해결 방식

최종 분류 결과만 보고 맞고 틀림을 판단하지 않고 중간 레이어의 출력부터 비교했습니다. 차이가 발견되면 연산 범위를 더 좁혀 MAC 단위까지 확인하는 방식으로 SW와 HW 사이의 불일치 원인을 추적했습니다.

합성 이후에도 RTL과 Netlist를 같은 테스트 입력으로 비교해 기능이 유지되는지 확인했습니다.

## 보여주는 역량

- AI 모델의 정수화와 HW 표현 이해
- Python과 Verilog 사이의 데이터 형식 연결
- 중간 결과 기반 디버깅
- RTL 및 합성 Netlist 검증
- 정확도와 PPA를 함께 보는 HW/SW co-design 관점
