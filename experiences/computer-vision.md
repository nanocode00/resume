# Computer Vision Coursework & Practice

## 학습 내용

- 디지털 이미지 형성과 노이즈
- convolution과 filtering
- gradient와 edge detection
- binary image analysis
- segmentation과 clustering
- feature point 기반 matching
- 직선과 형태 검출
- image warping과 stitching
- object recognition

## 직접 수행한 실습

- 임계값 변화에 따른 영상 분할 결과 비교
- 평균 필터와 Gaussian 필터 비교
- 커널 크기와 sigma 변화에 따른 노이즈 제거와 경계 보존 분석
- Canny의 커널과 상·하한 임계값 조정
- separable filter 구현과 결과 검증
- Manhattan distance transform
- Chamfer Matching
- color clustering
- Hough Transform
- RANSAC 기반 line fitting

## 배운 점

같은 입력이라도 촬영 조건과 파라미터에 따라 결과가 달라질 수 있음을 여러 실습에서 확인했습니다.

알고리즘을 적용하는 것으로 끝내지 않고 원본 이미지와 처리 결과를 비교하면서 목적에 맞는 설정을 선택하는 습관을 익혔습니다. 이 방식은 HummingBlocks에서 실제 촬영 환경에 따른 인식 문제를 확인하거나 AI/HW 프로젝트에서 중간 결과를 비교하는 방식과도 이어집니다.

## 보여주는 역량

- 전통적 Computer Vision 기본기
- 파라미터 변화에 따른 결과 비교
- 입력과 중간 처리 과정을 함께 확인하는 디버깅 관점

## 자소서 활용 포인트

- Computer Vision 직무 준비
- 영상처리 기본기
- 이미징 분야 관심과 학습 과정
