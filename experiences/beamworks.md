# Beamworks Internship

## 한 줄 요약

Figma 화면의 요구사항을 Jira 업무 단위와 ERD, DB, SQL, DTO 구조로 변환하며 실제 개발 전 설계 과정을 경험한 현장실습.

## 프로젝트 성격

Beamworks는 의료 AI 기업이지만 현장실습에서 맡은 업무는 의료영상 개발이 아니라 **사내 업무관리 플랫폼**이었습니다.

이력서나 자소서에서 의료영상 경험으로 과장하지 않고 요구사항 분석, 데이터 설계, 협업 프로세스 경험으로 사용합니다.

## 주요 작업

- Figma 화면을 바탕으로 기능 요구사항 분석
- 화면의 값을 입력값, 조회값, 저장값으로 구분
- Jira의 Epic, Story, Task로 업무 구조화
- ERD 설계
- DB 테이블 설계
- SQL 작성
- DTO 작성

## 배운 점

화면에 보이는 기능을 구현하려면 버튼이나 입력창 자체보다 그 뒤에서 어떤 데이터를 받고, 어디에서 조회하고, 무엇을 저장해야 하는지 정의해야 한다는 점을 경험했습니다.

또한 요구사항을 바로 코드로 옮기기 전에 개발 가능한 크기의 업무 단위로 나누고 데이터 구조를 먼저 설계하는 과정이 필요하다는 것을 배웠습니다.

## 보여주는 역량

- 요구사항 분석
- 화면과 데이터 구조 연결
- Jira 기반 업무 구조화
- ERD/DB 설계
- SQL 및 DTO 작성
- 개발 프로세스 이해

## 자소서 활용 포인트

- 현장실습 경험
- 실무 협업 방식
- 요구사항을 개발 단위로 구체화한 경험
- Backend/Software 직무 준비
