## 한 줄 요약

**Raspberry Pi 기반 가정용 CCTV를 만드는 4인 팀 프로젝트에서 Python 카메라 영상 저장과 카메라의 네트워크 연결을 진행하고, 영상인식 구현의 기술적·시간적 제약 이후 담당 범위를 녹화 영상 조회 웹서버로 조정하여 최종 발표에서 완료로 보고했다.**

이 경험에서 강조할 점은 **처음 목표한 영상인식이나 실시간 원격 CCTV를 완성했다는 사실이 아니라**, 실제 일정과 구현 가능성을 고려해 **영상을 저장하고 웹에서 조회하는 흐름을 구축했다는 것**이다.

[별도 경험 문서](highschool-theft-prevention-camera.md)와 [해당 고교 원본·코드 원장](highschool-theft-prevention-evidence-ledger.md)을 참조.

## 대표 사례 — 상황 → 문제 → 판단 → 조치 → 결과

### 상황

2019년 4인 팀으로 **Raspberry Pi와 카메라를 이용해 집의 상황을 확인할 수 있는 CCTV**를 제작했다. 팀은 카메라 촬영·저장, PIR 모션 인식, 서보모터, 카카오 챗봇 및 영상인식 기능을 검토했다. 본인은 중간 단계에서 **카메라 영상 저장용 Python 코드**, 이후 **카메라와 네트워크 연결**을 담당했다.

### 문제

처음 목표했던 **영상인식 기능**은 팀 최종 발표에서 **기술적·시간적 문제로 구현하지 못했다고 명시**되어 있다. 초기 목표를 그대로 주장하기보다 일정 안에 동작하는 녹화·조회 흐름을 만들어야 했다. 이는 팀 문서에 적힌 제약이며 **특정 성능 문제·모델·실패 로그는 확인되지 않았다**.

### 판단

최종 발표에서는 영상인식을 통한 동작 추적 대신 **이미 촬영해 저장한 영상을 웹에서 확인하는 기능**으로 본인 역할이 바뀌었다. 이를 프로젝트의 최종 구현 가능 범위로 채택했다는 것은 발표자료에서 확인되지만 **누가 변경을 제안했는지, 내부 의사결정 과정, 개인이 주도한 정도**는 기록이 없다. 따라서 '본인이 독단적으로 전략을 결정했다'고 서술하지 않는다.

### 조치

- **Python을 이용한 영상 저장 기능**을 작성했다는 사실이 **1차 중간 발표의 개인 기여 표**에 기재되어 있다.
- **Raspberry Pi 카메라와 인터넷 기능 연결**, 영상 조회 코드 작성이 **2차 중간 발표의 개인 기여 표**에 기재되어 있다.
- 마지막에는 **녹화된 동영상을 보는 웹서버 구축**을 맡았으며 최종 발표에서 완료로 표시되어 있다.
- 보존된 `index.html`에는 **`<video src="video.mp4" controls loop>`**로 브라우저 영상 재생, **`download="video.mp4"`**로 파일 다운로드 링크가 있다. 원본 프로젝트 폴더에 **Apache2 Debian Default Page** 저장 파일도 있어 Apache 환경을 시험한 흔적과 부합한다.
- 팀 폴더의 `cctv.py`에는 **PIR GPIO 감지값을 연속 확인해 30초 촬영**, **MP4Box로 H.264를 MP4로 변환**, 최신 파일을 **`/var/www/html/video.mp4`로 복사**하는 흐름이 있다. **이 통합 스크립트를 혼자 작성했다고는 주장하지 않는다**. 최종 발표상 PIR-영상 녹화 통합은 **다른 팀원**의 담당이다.

### 결과

팀의 최종 발표에는 본인의 **녹화 영상 조회 웹서버 구축을 '완료'**라고 기재했고, 다른 팀원들이 구현한 **챗봇 조회·다운로드·PIR 감지 및 녹화**도 각각 완료로 기록했다. 원본 `index.html`, `cctv.py`, 저장된 MP4와 최종 시연 영상 파일이 남아 있어 당시 구조와 산출물을 교차 확인할 수 있다.

**그러나 '실시간 스트리밍 CCTV', '스마트폰에서 언제 어디서나 접속 가능한 상용 서비스', '영상인식/객체 추적 구현 성공', '웹서버 전체 스택 직접 코딩'은 확인된 결과가 아니다.** 브라우저 재생 HTML은 확인되지만 당시 배포된 외부 접근 URL·접근권한·네트워크 공개 설정·대규모 사용 시험은 찾지 못했다.

## 기술·산출물에서 확인되는 구체적인 사실

- **하드웨어:** Raspberry Pi, 카메라, PIR 센서. 서보모터·Arduino는 팀의 중간 계획/시연 내용으로 존재하나 웹서버 담당 성과와 구분.
- **언어/도구:** Python `picamera`, `RPi.GPIO`, HTML5 `video`·다운로드 링크, **Apache2 문서 루트 정황**, `MP4Box`를 이용한 H.264→MP4 변환. **라이브러리 내부나 Apache 자체를 처음부터 구현한 것으로 주장하지 않는다.**
- **보존된 팀 파일:** `cctv.py`, `video_record.py`, `video_record_2.py`, `capture.py`, `PIR.py`, `index.html`, 영상과 시연 파일. 각 파일의 **Git 작성자·커밋 이력은 없음**.
- **검토 방식:** 발표된 결과와 코드의 **정적 구조**를 교차 확인했다. 당시 Raspberry Pi 하드웨어를 재구동하거나 보존된 최종 영상을 실제 재생 검증한 것은 아니다.
- **기간:** 2019년 가을 팀 회의 기록이 **10월 30일~12월 2일**로 표시되어 있다. 정확한 과목명/전체 수행일/학점/수상은 이번 근거로 확정하지 않는다.
