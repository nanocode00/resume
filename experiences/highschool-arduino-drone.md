# 고교 Arduino 드론 — 교재·키트 실습으로 비행 제어 원리 학습

> **2026-10-29 직접 회고**와 개인 Drive의 `드론 코드/` 단계별 Arduino 소스, 기존 Paperware 복원 원장을 대조했다. 이는 **교재 및 키트를 직접 구입해 조립·실행해 본 학습 활동**이며, **PID 비행제어 알고리즘을 직접 처음부터 작성한 개발 프로젝트로 기재하지 않는다.** 자세한 구분은 [근거 원장](highschool-arduino-drone-evidence-ledger.md).

## 한 줄 요약

고등학생 때 **Arduino 드론 제작 교재와 키트를 구입해 직접 조립하고 실행·실험하면서** 센서로 기체 자세를 추정하고 네 모터 출력을 제어하는 기본 원리를 배웠다. **이 경험은 이후 Paperware의 카드보드·micro:bit 드론 기체 제작과 무선 컨트롤러 구현을 시도하는 기반이 됐다**는 점을 2026-10-29 본인이 직접 확인했다. 두 제작 활동의 성공·실패, 사용 하드웨어, 프로그램 저작 여부는 별개로 관리한다.

## 상황 → 문제 → 판단 → 조치 → 결과

### 1. 상황

고교 시절 Arduino와 센서·액추에이터에 관심을 갖고, 친구와 함께 드론의 실제 작동 방식을 알아보고자 했다. 당시 **Arduino 드론 교재와 키트를 구매**해 책의 절차에 따라 실습을 진행했다(본인 회고). 정확한 책 제목·제품/보드 모델·구매 시점·공동 실습자의 역할은 확인하지 않았다.

### 2. 문제

단순히 프로펠러가 회전하는 것을 넘어 드론이 **어떻게 기울기를 측정하고, 모터 네 개를 제어해 자세를 유지하려는지** 이해하고 싶었다는 활동 목적을 기술적으로 정리할 수 있다. 단, 이것은 **이번 회고의 ‘원리를 이해했다’는 말을 보존 코드와 연결해 설명한 해석**이지 당시 사용자가 자체 비행제어 알고리즘 개발을 목표로 세웠다는 증거는 아니다.

### 3. 판단

기체, 센서, 회로, 통신, 제어를 모두 처음부터 설계하기보다는 **시판 교재·키트와 제공 예제를 실제 기체에서 따라 해 보는 방식**을 택했다. 단계별로 동작을 확인하며 원리를 학습하는 데 중점을 뒀다. 코드의 주 알고리즘은 **교재 예제**이므로 개인 창작물과 구분한다.

### 4. 조치

- **교재·키트 구입 후 기체 조립·실습:** 본인이 직접 키트를 다뤄 보며 드론 동작을 관찰했다(2026-10-29 회고). 과거 자기 Notion 기록에도 친구와 Arduino 드론 제작·코딩·비행을 시도했다는 내용이 남는다. 다만 **자유 비행·안정화 성능·비행 시간·개별 문제 해결은 정량 증거가 없다**.
- **단계별 Arduino 예제 확인:** 보관된 `드론 코드/`에는 `_01hellodrone`, `_09mpu6050rawdata`, `_10ypr`, `_11stdpid`, `_15dualpid`, `_16drone_remote` 등 **16개 주요 단계명**의 스케치 폴더가 있다. 이것은 단계별 코드를 **보유했다는 사실**이지 모든 단계를 직접 새로 코딩했거나 하드웨어에서 완주했다는 증거는 아니다.
- **자세 추정·모터 제어 흐름 읽고 실행 시도:** 보존된 `drone.ino`·`_10ypr.ino`·`_15dualpid.ino`·`_16drone_remote.ino`에는 **MPU6050 I²C 센서 읽기, 자이로/가속도 기반 Roll/Pitch/Yaw 추정, PID 피드백, 모터 속도 계산, MSP 형식 명령 수신** 등의 코드 흐름이 들어 있다. **알고리즘의 직접 저작을 주장하지 않는다**.
- **후속 활용:** 이후 Paperware에서 **카드보드 기반 기체·micro:bit 버튼/기울기 입력 기반 무선 컨트롤러**를 제작·실험할 때, 당시 드론의 작동 원리를 이해했던 경험을 기반으로 삼았다(2026-10-29 직접 회고). **그 컨트롤러의 `controller.py`는 기존 기록상 본인이 직접 작성한 후속 작업**으로, 고교 Arduino 교재 코드와 구별된다.

### 5. 결과

- **확인된 결과:** 교재와 키트의 실제 조립·동작을 통해 **드론의 기본 원리를 이해한 학습 경험**, 이를 **후속 Paperware 드론 시도로 연결했다는 직접 회고**.
- **별도 후속 결과:** 2018년 Paperware 관련 카드보드 드론은 **실제 기체 제작·무선 조종 시도까지 했으나**, 무게에 비해 모터 추진력이 부족해 **이륙 실패**(2026-10-24 사용자 직접 확인 및 기존 Paperware 조사 문서). **이는 후속 Paperware 기체의 결과이지, 고교 Arduino 교재 키트의 실패 결과가 아니다.**
- **기술·성과 제한:** 고교 교재 키트의 비행 성공 범위, 실측 자세 제어 정확도, PID 튜닝 여부, 새로운 회로/모터 선정, 파일별 개인 수정량, 수상·상용화는 미검증이다.

## 이력서·면접용 문장

> **Arduino 드론 교재·키트 학습 (고교 시절)** — 시판 Arduino 드론 제작 교재와 키트를 직접 구매해 조립·실습하면서 **자세 센서와 모터 제어를 연결하는 드론의 작동 원리**를 익혔습니다. 이 경험을 바탕으로 이후 **Paperware 카드보드 드론과 micro:bit 무선 컨트롤러** 제작·조종을 시도했습니다. 후속 기체는 추진력 부족으로 이륙하지 못했으며, **교재의 비행제어 코드는 개인 독자 구현으로 기재하지 않습니다.**

**권장 활용:** 기술 학습→자체 프로젝트로 응용하는 **성장 과정**. 고교 활동 자체를 ‘자율비행 알고리즘 개발’, ‘PID 튜닝을 통한 안정 비행’, ‘개발한 드론 출시’로 포장하지 않는다. 대학 이후 대표 기술 프로젝트와 같은 수준으로 중복 합산하지 않는다.
