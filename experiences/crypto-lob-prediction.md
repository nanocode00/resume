# Crypto LOB Prediction

## 한 줄 요약

거래소 호가와 체결 데이터를 수집하고 CNN과 Mamba를 결합한 시계열 분류 모델로 단기 가격 방향을 예측한 뒤, 정확도뿐 아니라 거래 수수료를 포함한 백테스트로 실제 활용 가능성을 검토한 프로젝트.

## 주요 작업

- 거래소 호가 및 체결 데이터 수집
- 시계열 데이터 전처리
- CNN 기반 특징 추출 실험
- Mamba를 결합한 분류 모델 실험
- 5초 및 15초 뒤 가격 방향 예측
- 분류 정확도 평가
- 거래 수수료를 반영한 백테스트

## 핵심 경험

모델의 validation accuracy가 높아지는 것만으로 실제 거래 전략이 유효하다고 판단하지 않았습니다. 예측 결과를 실제 매매로 연결했을 때 수수료를 포함한 손익이 어떻게 달라지는지 확인했습니다.

이 과정을 통해 모델 지표와 서비스 또는 실제 사용 환경의 성과는 다를 수 있으며, 문제에 맞는 최종 평가 기준을 따로 확인해야 한다는 점을 경험했습니다.

## 보여주는 역량

- 시계열 데이터 처리
- Deep Learning 모델 실험
- CNN/Mamba 구조 활용
- 평가 지표와 실제 성과의 차이 검증
- 결과가 기대와 다를 때도 수치로 확인하는 태도

## 자소서 활용 포인트

- AI/데이터 직무 준비
- 실험과 검증 경험
- 기대와 다른 결과에서 배운 경험
- 모델 성능을 실제 사용 관점에서 평가한 경험
