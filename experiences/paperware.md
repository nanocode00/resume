# Paperware — micro:bit 메이커 키트 및 커스텀 PCB

> **자료 재조사 상태 (2026-10-24):** 과거 발표자료와 회고에서 확인한 사실을 분리한 초안이다. 특히 2018~2019년 기획·제작 활동과 군 복무 후 PCB 모듈 작업이 하나의 연속 프로젝트인지 **미확정**이다. 이를 확인하기 전까지 전체 기간이나 모든 산출물을 한 사람의 일관된 개발 성과로 묶지 않는다.

## 한 줄 요약

micro:bit와 카드보드·구리박 테이프를 활용한 코딩/메이킹 교육 키트 활동에서, 납땜을 전제로 한 기존 NeoPixel 모듈의 불편함을 해결하기 위해 카드보드 회로에 맞는 넓은 접점의 커스텀 PCB를 설계하고 시제품을 발주해 무드등 제작에 적용한 경험이다. 이 PCB 작업은 당시 작성한 개인 회고에 근거하며, CAD 원본·발주 내역·전기적 시험 기록은 이번 조사에서 확인하지 못했다.

## 2. 핵심 경험 — 상황 → 문제 → 판단 → 조치 → 결과

### 상황

micro:bit를 카드보드 및 구리박 테이프 기반 회로와 연결해 사용자가 직접 조립하고 코딩하는 교육용 메이커 키트를 제작했다. 카드보드의 가공 용이성, 낮은 재료 부담과 모듈 조합을 통한 확장성이 제품 기획의 주요 방향이었다. 2018년 팀 발표에는 드론형 제작 사례가, 후속 개인 회고에는 무드등 제작 사례가 남아 있다.

### 문제

기존 NeoPixel 모듈은 납땜이 필요한 연결 구조라 구리박 테이프와 카드보드를 활용한 키트에서 쉽게 연결하기 어려웠다. 교육용 조립 과정에서 사용할 수 있는 접점·연결 방식이 필요했다.

이는 당시 본인이 남긴 문제 인식이며, 납땜 과정의 시간·실패율 등을 정량 측정한 기록은 현재 확인되지 않는다.

### 판단

기존 모듈 사용법을 복잡하게 안내하는 대신 카드보드 회로에 직접 닿는 **커스텀 PCB의 접점 형상**을 바꾸는 방향을 선택했다. 고등학생 시절 스스로 익혔던 PCB 설계 경험을 활용해, 제품의 교육적 목적에 맞게 하드웨어 연결 구조 자체를 조정하려 했다.

### 조치

- 카드보드 회로와 접촉할 수 있도록 접점을 넓힌 NeoPixel PCB 모듈 설계
- 커스텀 PCB 시제품 주문
- 제작한 모듈을 카드보드 무드등에 적용
- 모터 등 다른 모듈의 회로도 구상·설계

마지막 항목은 **발주 전 프로젝트가 종료**됐으므로 실제 PCB 제작·동작 검증으로 확대하지 않는다.

### 결과

NeoPixel PCB 시제품을 주문하고 무드등 제작에 활용한 경험이 회고에 남아 있다. 다만 사용자 테스트, 납땜 작업 감소율, 교육 효과, 판매량, 최종 양산·보급 여부는 확인된 자료가 없다. 따라서 결과는 **커스텀 모듈 설계와 제한된 시제품 적용**으로 표현한다.

## 3. 관련 기획 자료에서 추가로 확인한 방향

### 2018 Paperware 자료

- 2018.05 발표에는 카드보드의 친숙함·저렴함·재활용 가능성, micro:bit를 통한 메이커 교육이 핵심 가치로 제시됨.
- 보관 폴더에는 카드보드 드론의 도면·이미지 및 2018년 사진 기록이 있음.
- 당시 팀 활동의 증거는 되지만, 개별 사진·도면을 모두 본인이 제작했다고 주장하지 않는다.

### 2019 Link Cube 제안서

- 기존 micro:bit 링 단자와 확장보드의 연결 불편함, 모듈 연결 제약을 문제로 제시.
- 사용자 선택에 따라 **센서/액추에이터 3개를 장착**하는 큐브 형태와 슬롯 구조를 제안.
- 무드등·RC카·선풍기 등은 **응용 가능성 예시**이며 실제 구현·판매 제품 목록으로 사용하지 않는다.
- 전선이 꺾이거나 교차하는 문제에 대해 스티커형 flat cable 구조를 구상함.
- 제안서의 역할 표기상 김재훈은 ‘코딩’에 해당하며, 실제 코드·작동 검증 산출물은 이 제안서만으로 확인되지 않는다.

2018 Paperware, 2019 Link Cube, 이후 NeoPixel PCB 작업은 사용자 중심 메이커 교육과 모듈 연결 방식이라는 공통 주제를 갖지만 **사업·제품·팀 관계는 아직 미확정**이다.

## 5. 이력서·포트폴리오 활용 후보

**상세 경험기술서용 문장 (잠정):**

> micro:bit 기반 카드보드·구리박 테이프 교육 키트에서 일반 NeoPixel 모듈의 납땜 연결 문제를 해결하기 위해 접점을 확장한 커스텀 PCB를 설계하고 시제품을 제작 의뢰해 카드보드 무드등에 적용했습니다. 모듈 설계를 교육용 조립 환경의 제약에 맞춰 바꾸는 사용자 중심 하드웨어 개선 경험이었습니다.

**활용 위치:** SW/AI Backend 중심 이력서의 상단 핵심 성과보다는, 메이커·임베디드·HW/SW 융합 직무에서 **제약을 분석하고 소형 하드웨어를 개선한 보조 사례**가 적합하다.

**표현상 주의:**
- Paperware를 2018~2021년 단일 기간의 연속 개발 프로젝트로 단정하지 않는다.
- Link Cube 2019 제안 기능과 모터 PCB를 완제품으로 주장하지 않는다.
- 전체 키트·드론·코딩 플랫폼의 단독 구현을 주장하지 않는다.
- 납땜 감소, 정확성·신뢰성 향상, 사용자 만족 등 측정치가 없는 결과를 수치화하지 않는다.
- 15회 교육 실적을 Paperware의 단일 프로젝트 성과로 붙이지 않는다.

2. **당시 설계 데이터:** NeoPixel PCB의 CAD 원본, Gerber, 주문·시제품 사진, 수정 이력 등이 남아 있는가?

4. **동작 검증:** 무드등 적용 당시 전기적 연결·LED 동작을 어디까지 검증했고, 오류나 수정 iteration이 있었는가?
5. **교육 실적:** 15회 교육이 어떤 프로그램에 귀속되는지 자료 확인이 필요한가? (본 프로젝트에는 현재 미귀속)

## 7. 네모감성 전체 폴더 추가 조사 (2026-10-24)

별도 사용자 보관 `네모감성/` 폴더를 확인해 **2018년의 micro:bit 무선 조종·드론 코드**, **2019년 Link Cube 기획/무드박스 제어자료와 HEX**, **2020년 micro:bit 교육 예제**를 추가 발굴했다.

`팀플/마이크로비트 코드/controller.py`에는 버튼 조합·가속도 X/Y값을 라디오 명령으로 변환하는 MicroPython 제어 코드가 있으며, **사용자가 직접 작성했다고 확인했다**. 다만 `팀플/drone/drone.ino`는 **드론 관련 도서에서 제공된 예제**로, 여기에 포함된 MPU6050 읽기·complementary filter·PID·모터 PWM 코드를 본인 직접 구현으로 주장하지 않는다. 수신 코드 `radio_test.py`의 작성자, 컨트롤러와 기체의 연동·비행 검증, Paperware 프로젝트와의 관계는 아직 미확정이다.

`다른코리아 미팅발표용.pptx`에 김재훈은 ‘코딩’ 담당으로, 2019년 `피티 제작.pptx`에는 CTO로 표기되어 있다. `추가 자료설명.pptx`에는 NeoPixel/기울기 기반 무드박스 제어를 설명하며, 관련 메인/컨트롤러 HEX가 존재한다. 이 사실은 기술적 역할을 좁히는 데 유용하지만 **최초 작성자·최종 작동·사업 성과를 증명하지는 않는다**.

초기 프로젝트를 분리한 전체 자료/소스 원장은 [네모감성 초기 메이커 증거 조사](nemogamsung-early-maker-evidence.md)에서 추적한다.
