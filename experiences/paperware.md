# Paperware

## 한 줄 요약

micro:bit를 카드보드와 구리박 테이프로 만든 회로에 연결하는 교육용 메이커 키트에서 기존 모듈의 사용성 문제를 발견하고 커스텀 PCB 모듈을 설계한 경험.

## 배경

군 복무 후 복학 전 친구와 네모감성 활동을 시작했고, 그 시기에 Paperware 프로젝트를 진행했습니다.

카드보드와 구리박 테이프를 이용해 회로를 만들고 micro:bit를 연결해 다양한 결과물을 만드는 교육용 키트였습니다.

## 문제

기존 네오픽셀 모듈은 납땜이 필요해 카드보드 기반 교육용 키트에서 바로 사용하기 어려웠습니다.

## 해결

고등학생 시절 익혔던 PCB 설계 경험을 활용해 카드보드에 바로 연결할 수 있도록 접점을 넓힌 커스텀 네오픽셀 모듈을 설계했습니다.

- PCB 설계
- 시제품 주문
- 카드보드 무드등 등에 적용
- 모터 등 다른 커스텀 모듈도 설계했으나 프로젝트 종료로 시제품 주문 전 중단

## 의미

새로운 기술을 크게 추가하기보다 실제 사용 과정에서 불편한 지점을 발견하고 작은 구조 변경으로 제작 방식 자체를 개선한 경험입니다.

## 보여주는 역량

- PCB 설계와 시제품 제작
- 사용자 관점의 하드웨어 개선
- Maker mindset
- 기존 경험을 새로운 문제에 재사용하는 능력

## 자소서 활용 포인트

- 창의적인 문제 해결
- 관심 분야와 흥미
- 하드웨어 제작 경험
- 스스로 배운 기술을 실제 결과물로 연결한 경험
